# 日本語 IME 修正の Windows 実機テスト

対象: Windows 10 / 11 の Intel・AMD 64 ビット版。

1. 通常版の DigUp が動いていれば、トレイのメニューから Quit してください。
2. ZIP の中身をフォルダごと展開します。
3. `Launch-IME-Test.cmd` をダブルクリックします。
4. モデルの準備・テスト文書の索引作成が終わるまで待ちます。既存モデルは再利用します。未取得の場合は約865MBのダウンロードが必要です。
5. `Ctrl+Alt+Shift+D` で検索パネルを開きます。今回のテスト用のショートカットです。

## 確認すること

パネルと大きい検索ウィンドウ（Ctrl+O）の両方で確認してください。

- 日本語 IME で「とうきょう」と入力し、未確定のまま1秒ほど待つ。文字や候補が途切れず、検索結果が変換途中の文字で次々切り替わらない。
- 「東京」に変換し、Enter で確定する。確定用の Enter で検索結果のファイルが開かず、確定した「東京」で検索される。
- 日本語を入力中に Escape で変換を取り消す。検索ウィンドウが閉じない。その後も入力できる。
- 確定後に文字を全部消す。古い検索結果が残らず、通常の空の検索欄に戻る。
- 英数字の入力、結果を選んで Enter で開く操作も従来どおり動く。

結果は「Windows 10/11、IME の種類（Microsoft IME / Google 日本語入力）、パネルと大きいウィンドウそれぞれの結果」を教えてください。

## テスト版の構成

- UI シェルは今回の IME 修正を含むソースからビルドしています。コミットは `BUILD-INFO.txt` で確認できます。
- 検索エンジンと依存 DLL は本家の 0.7.0-beta.2 配布物から取得し、配布物の SHA-256 を検証したものを使っています。
- 今回の入力制御の確認用です。最新エンジン全体や配布インストーラーの検証を目的とするビルドではありません。
- インストールは行いません。通常版の設定・索引と分け、`%LOCALAPPDATA%\DigUp-IME-Test` を使用します。検索対象は同梱の TestFiles だけです。
- モデルだけは `%LOCALAPPDATA%\DigUp\Models` を共有します。自動更新はテスト用設定で無効にしています。
- WebView2 Runtime が必要です。起動時に不足が表示された場合は、Microsoft 公式の WebView2 Runtime を導入してください。

終了時はトレイメニューから Quit。不要になったらテスト版の展開先と `%LOCALAPPDATA%\DigUp-IME-Test` を削除できます。共有している通常版の Models フォルダは削除しないでください。
